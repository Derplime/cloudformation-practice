# cloudformation-practice
Personal repository for practicing AWS CloudFormation

## Purpose of this repo

I wanted to get some exposure and get used to writing out CloudFormation templates, so spending some doing so and putting the progress in a repo.

### Learning Approach

Pretty much just dove into the AWS Console, and had Amazon Q provide me with a simple bare bones VPC setup. Then as I've been translating the idea into a CloudFormation template, I've had it suggest new stage of things to add on.

Those additions I write into a new CloudFormation template that has the prior stage's stuff, and I add the extra configurations that are needed to integrate the new additions to the existing template.

### Tooling Used

Just using VSCode and installed some extensions to help with linting/suggestions since I'm learning all the syntax as I go as well.
